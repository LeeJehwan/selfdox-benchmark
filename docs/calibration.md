# Threshold calibration

Generated by `uv run python -m tools.calibrate fit` from the frozen samples in
`data/calibration/calibration.jsonl` (no OCR or images needed to refit).

## Protocol

- **Lines:** 104 sign/text lines from Wikimedia Commons street photos that are
  *not* in the pilot set, found by Apple Vision OCR and kept only if re-reading the line
  crop reproduces the text (CER <= 0.2).
- **Edits** (2080 samples): identity, Gaussian blur (sigma = 0.03-0.3 x line
  height), pixelation (block 0.08-0.4 x height), box blur, JPEG Q15, noise, contrast x0.25,
  fill + JPEG, 60% sticker, blur over half the line. Edits are applied to the full image and
  scored through the real scorer code (`line_scores`).
- **Label ("attacker"):** Apple Vision reads the edited line crop as is, after CLAHE
  contrast enhancement, and inverted; the line is *legible* if any reading has CER <= 0.5
  against the reading of the original crop.
- **Null samples:** the line replaced by a different line from another photo (text gone,
  structure present). Their 99th-percentile window score is the noise floor; thresholds
  must be at least floor + 0.1.
- **Half-line blur** counts as legible by definition (the untouched half still leaks).
- **Objective:** maximize balanced accuracy subject to *false hidden* (legible but scored
  as hidden, the dangerous error) <= 5%.

## Caveats

- One OCR engine (Apple Vision) stands in for the attacker; a stronger reader (a VLM) can
  read some lines Vision can't, so "false retained" here partly reflects OCR weakness.
- Lines are mostly large shop signs; tiny text (< 16 px) is under-represented.
- Geometric tricks (mirror, shift, inversion) are not in the fit: OCR can't read mirrored
  text, but the scorer deliberately treats it as retained (unit tests cover these).

## Non-text clues (landmarks, skylines, facades)

Generated by `uv run python -m tools.calibrate_nontext fit` from
`data/calibration/nontext_samples.jsonl` and the judge answers.

- **Regions:** 120 landmark / skyline / facade boxes from the pilot GT and the
  model drafts (short side >= 32 px).
- **Edits:** Gaussian blur (sigma 0.02-0.25 x the box's short side), pixelation
  (block 0.04-0.3 x), mean fill, blur over half the box, JPEG Q15, horizontal flip,
  contrast x0.25, 15% shift. Scored through `line_scores(kind="non_text")`.
- **Judge ("attacker"):** Qwen3-VL-8B sees the original region (A) next to the edited one
  (B) and answers whether the same building or view is still recognizable in B
  (`cluster/prompts/nontext_judge_prompt.txt`). Half-covered regions count as leaking by
  definition, as for text.
- **Judge controls:** unedited pairs answered "yes" 100%
  (n=120); pairs with an unrelated region in B answered "no"
  82% (n=117).
- **Objective:** maximize balanced accuracy with *false hidden* (judge still recognizes it,
  scorer says hidden) <= 5%. The text rule (clear the unrelated-swap noise floor, p99 window score 0.651, by 0.1) cannot be met together with the cap: every such threshold calls many recognizable regions hidden. The cap wins; at the value in use 80% of unrelated swaps are scored hidden, so an agent that pastes other content over a landmark is sometimes not credited (the safe direction).

| | tau_nontext | false hidden | false retained | balanced acc. |
|---|---|---|---|---|
| fit: best balanced accuracy under the cap | 0.55 | 0.044 | 0.725 | 0.615 |
| **in use** (`config.TAU_NONTEXT`) | 0.5 | 0.031 | 0.770 | 0.599 |

Both values meet the cap. We keep 0.5: it leaves more margin under the 5% cap (3.1% vs 4.4%) and the gain in balanced accuracy at 0.55 is small (0.599 vs 0.615), so scores stay unchanged.

Pairs: 2147 judged (769 recognizable, 1141 not),
